## Límite de producto

El usuario ha acotado el MVP al **programa de desarrollo de software con IA**. No se implementan otros másteres, un catálogo multiprograma ni una formación general de productividad con IA. Los fundamentos son la entrada a este itinerario técnico.

Incluye landing, lectura de artículos Markdown, índice, navegación secuencial, búsqueda, filtros y progreso local. No incluye cuentas, pagos, comunidad, tutorías, vídeos, evaluaciones oficiales, certificados, ECTS ni promesas de empleo. La plataforma utiliza identidad visual y explicaciones propias.

Las duraciones son estimaciones propias de lectura y actividad, no horas lectivas acreditadas. Los talleres son propuestas escritas para esta plataforma.

## Siguiente objetivo: revisión y contenido propio

Revisar cada módulo para mejorar claridad, progresión y profundidad; comprobar sus ejemplos y ejercicios; añadir casos propios y proyectos verificables. Cada revisión debe registrar los cambios, actualizar la fecha de la lección y mantener objetivos, requisitos y criterios de aceptación coherentes. La revisión pedagógica completa está pendiente y no se sustituye por los tests de estructura.

## Tratamiento de herramientas cambiantes

Cada lección enlaza documentación primaria para ampliar y verificar. Los ejemplos con servicios de pago se plantean con datos sintéticos, límites y alternativas o mocks cuando corresponda. No se incluyen claves, se evita ejecutar automáticamente comandos sobre entornos ajenos y no se garantiza que la salida de un modelo sea correcta. Las ediciones de OWASP se identifican en el artículo correspondiente, sin tratar un rótulo comercial como prueba de una edición publicada.

## Edición y trazabilidad

El currículo es el inventario de referencia, el frontmatter valida metadatos y el build falla si falta una lección, hay un archivo huérfano o el título/orden no coincide. Los tests comprueban cobertura, mínimos didácticos y fuentes; no equivalen a revisión pedagógica humana exhaustiva ni certifican que todos los ejercicios se hayan ejecutado.
